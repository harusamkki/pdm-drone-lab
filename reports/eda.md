## 4. 다음 단계에서 판단할 사항

- fault_code·fault_category의 결측이 예방정비의 고장 없음인지 위 정비 유형별 표를 보고 결정한다.

- 운용중단 시간·비용의 극단값은 원본 값을 보존한 채 입력 코드 또는 단위 오류 여부를 확인한다. 이전 실습의 보정 규칙을 자동 적용하지 않는다.

- 경과일 결측은 이전 파일의 정비 이력과 이어서 확인해야 한다. 파일 경계에서 실제 첫 정비로 오인하지 않는다.

- availability_rate는 그 달 전체 가동률이므로 정비 직후에 알 수 없는 누수 후보이며 이번 달 파일에도 없다. 예측 입력에서 제외할 근거로 기록한다.

- 드론 유형·정비 유형·계절의 비율 차이는 구성비와 표본 수의 영향을 받는다. 원인이나 미래 성능으로 단정하지 않는다.

- 시험·이번 달에는 정답이 없으므로 재고장 비율이나 모델 성능을 계산하지 않았다.

- 위 표는 원본 집계다. 데이터 처리·피처 검증의 진행 상태는 아래 검증 기록을 따르며 모델 학습·예측·대상 선정은 별도 단계다.



## 5. 확정한 처리 방침 (3단계)

근거: AGENTS.md의 데이터 처리 규칙. 위 표는 보정 전 원본 집계이며 처리 구현과 검증은 다음 절에서 구분한다.

- 원본의 복사본에서 처리하며 행·행 순서·인덱스를 보존한다. 시험 제출은 원본 1,241행 모두와 일대일로 대응해야 한다.
- `downtime_hours`의 정확히 999인 값은 미상 입력 코드라는 실습 가정으로 결측값(NaN)으로 바꾼다. 학습 데이터 4건이 해당한다. 다른 큰 값은 자동 삭제하거나 평균으로 바꾸지 않는다.
- `maintenance_cost`의 학습 데이터 차수 오류 의심값 15,000·16,200·16,800·18,300·19,000은 실습 처리 가정으로 100으로 나눈다. 비용 단위는 만원이다. 이 값들을 제외한 학습 최댓값은 478이며 보정 후 값 150·162·168·183·190은 그 범위 안이다. 다른 비용에는 임의로 같은 규칙을 확대하지 않고 새 극단값은 별도로 확인한다.
- 위 두 보정은 분포에 근거한 가정이며 데이터만으로 입력 오류 원인을 확정한 것은 아니다. 보고서에 가정과 적용 건수를 명시한다. 시험·이번 달 데이터의 분포나 시험 성능으로 보정 기준을 조정하지 않는다.
- `fault_code`·`fault_category`의 결측은 `maintenance_type`이 예방정비인 경우 문자열 `N/A`로 채운다. 학습 1,707건, 시험 876건, 이번 달 62건은 각각 모두 예방정비이다. 사후·긴급정비에서 새 결측이 발견되면 고장 없음으로 바꾸지 않고 미확인으로 남겨 보고한다. 최빈값으로 고장 유형을 만들어 넣지 않는다.
- `days_since_last_maintenance`의 결측은 유지하고 `is_first_maintenance` 열을 결측이면 1, 아니면 0으로 만든다. 이번 데이터의 결측 150건은 드론당 1건이며 전체 제공 이력의 최초 정비일과 일치한다. 표시는 제공 이력의 최초 기록이라는 의미이며 실제 생애 첫 정비라고 단정하지 않는다. 경과일을 0으로 채우지 않는다.
- 다른 수치 결측은 이 단계에서 임의로 채우지 않는다. 이후 모델이 대체를 필요로 하면 학습 구간에서만 대체값을 추정하고 검증·시험·이번 달에 그대로 적용한다.
- 시간 피처는 해당 드론의 정비일 이하 기록만 사용한다(같은 날짜 포함). 이후 날짜의 기록이나 정답은 피처 계산에 사용하지 않는다. 시험·이번 달 기록은 이전 기간 이력을 이어서 계산하되 파일 경계를 첫 정비로 간주하지 않는다.
- 입력 제외 대상은 `availability_rate`(정비 직후 알 수 없는 월 전체 가동률), `equipment_id`·`unit_code`(식별자), `maintenance_date`(기간 분리·이력 계산에만 사용), `fault_code`(고장 유형으로 대체), `failure_within_30days`(정답)다. 구체적인 최종 피처 목록은 학습 전에 확정한다.

- 재점검 비용은 60만원으로 고정한다. 총비용 = 놓친 재고장 수 × 해당 비용 + 기준 이상 건수 × 60만원.
- 기준 0.05~0.94를 0.01 간격으로 탐색하고 동률이면 낮은 기준을 고른다.

## 결과

| 놓친 재고장 비용(만원/건) | 기준 | 기준 이상 건수 | 놓친 재고장 수 | 최소 총비용(만원) |
|---|---:|---:|---:|---:|
| 150 | 0.30 | 156 | 28 | 13,560 |
| 300 | 0.26 | 171 | 24 | 17,460 |
| 600 | 0.10 | 287 | 11 | 23,820 |

## 검토
- 300만원 기준 0.26이 기존 모델 정보와 일치했다.
- 150만원 → 300만원 → 600만원 기준은 0.30 → 0.26 → 0.10이다. 비용이 커질수록 기준이 내려가는 예상과 일치한다.
- 건수는 검증 기간 전체 정비 기록 기준이다. 드론 중복을 제거한 월 20대 선정이나 용량 제약을 반영한 최적화가 아니다.
- 비용 가정별 총비용은 다른 단가로 계산하므로, 그 크기만으로 어느 가정이 더 좋은지 판단하지 않는다.
- 동일 검증 기간에서 기준을 선택한 결과이며 독립 시험 성능이나 실제 비용 절감을 보장하지 않는다.
- 현재 모델의 임계값과 모델 파일·학습 코드는 유지했다. 운영 비용 판단과 최종 결정은 정비 담당자가 한다.
